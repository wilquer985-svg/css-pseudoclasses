
# CSS Explorer 🔵

## Enciclopedia visual e interactiva de pseudoclases CSS

CSS Explorer es un proyecto web educativo diseñado para aprender, explorar y comprender las pseudoclases de CSS mediante ejemplos visuales e interactivos.

## 🚀 Características

- Catálogo de 29 pseudoclases CSS.
- Ejemplos de código CSS.
- Demostraciones interactivas.
- Buscador de pseudoclases.
- Filtros por categorías.
- Ventanas modales con explicaciones.
- Diseño adaptable a dispositivos móviles.

## 📚 Categorías

- Interacción
- Estructura
- Formularios
- Lógicas

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 💻 Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta `css-pseudoclasses` en Visual Studio Code.
3. Abre el archivo `index.html` con Live Server.
4. Explora las diferentes pseudoclases CSS.

## 🎯 Objetivo

Facilitar el aprendizaje de las pseudoclases CSS mediante una experiencia visual, práctica e interactiva.

## 👨‍💻 Autor

Proyecto educativo desarrollado como práctica de desarrollo web.
