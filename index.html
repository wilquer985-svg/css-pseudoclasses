ESTRUCTURA

:nth-child()

Selecciona un elemento según su posición entre los hijos de su padre.

li:nth-child(2) {
    color: blue;
}
ESTRUCTURA

:nth-last-child()

Selecciona un elemento contando su posición desde el último hijo.

li:nth-last-child(2) {
    color: orange;
}
ESTRUCTURA

:first-of-type

Selecciona el primer elemento de un tipo específico entre sus hermanos.

p:first-of-type {
    color: green;
}
ESTRUCTURA

:last-of-type

Selecciona el último elemento de un tipo específico entre sus hermanos.

p:last-of-type {
    color: red;
}
ESTRUCTURA

:nth-of-type()

    color: blue;
}
ESTRUCTURA

:only-child

Selecciona un elemento que es el único hijo de su padre.

    color: purple;
}
ESTRUCTURA

:only-of-type

Selecciona un elemento que es el único de su tipo entre sus hermanos.

}
ESTRUCTURA

:empty

Selecciona elementos que no tienen hijos ni contenido de texto.

}

}

}
